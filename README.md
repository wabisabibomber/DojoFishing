# DojoFishing

効果音検出オートクリックツールです。監視対象アプリの特定の効果音を検出すると、左クリック→待機→左クリックというシーケンスを実行します。

## 使い方

1. ZIPを展開し、DojoFishing.exeを起動します。ランタイム非同梱版では.NET 10 Desktop Runtimeが必要です。
2. 監視対象のプロセスを設定します。ここで指定したアプリケーションの音を監視し、クリックを制御します。
3. 検出閾値とクリック間隔を調整します。初期値は0.55です。誤検出する場合は閾値を上げ、検出しづらい場合は下げてください。
4. 「監視開始」を押し、対象アプリを最前面にします。クリックしたい場所にカーソルを置いてください。
5. 「監視停止」またはCtrl+Alt+F10で停止します。ホットキーは変更できます。
